This is a toy visualizer of the G-Machine described in [The Implementation of Functional Programming Languages](https://simon.peytonjones.org/slpj-book-1987/) by Simon Peyton Jones.

The G-Machine describes a runtime machine that can execute a high-level purely functional and lazy programming language based on the lambda calculus.
It is useful for providing a straightforward mapping from high-level Haskell- or Miranda-like languages to sequential machine code.

This toy app compiles a basic purely functional lazy language to intermediate G-Code and then it visualizes the execution of the program.

It is implemented in Elm.
